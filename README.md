# JavSport

JavSport is a multi-sport sports-wager analysis application built with Python and Streamlit. It brings together a daily game schedule, team performance metrics, user-provided odds and sport-specific data, then presents estimated win probabilities alongside the market-implied probabilities for each matchup.

The project supports **MLB, NBA, NCAA Basketball, NCAA Football, NFL, and WNBA**. It is a project for exploring data collection, parsing, metric assembly, and interactive sports analysis, but it is NOT a promise of profitable outcomes.

## Features

- Dedicated pages for six professional and collegiate sports.
- Loads the current day's schedule and sport-specific team statistics.
- Accepts user-uploaded files and parses them into structured tables.
- Builds matchup-level metrics, including home/away splits and MLB starting-pitcher metrics.
- Displays the model estimate, market-implied probability, and percentage-point difference for the predicted side.
- Provides results and source-data views, plus a control to reload a sport's data.

## Supported sports and uploads

All sports require a moneyline file in **MHTML** format, along with other file-dependencies that differ across sports.

## How it works

1. Choose a sport page. JavSport loads that sport's current-day schedule.
2. Upload the required files in the appropriate formats (listed).
3. The app retrieves team-level leaderboards and assembles per-matchup metrics.
4. A prediction service estimates the probability that Team A wins. The UI derives Team B's probability as the complement, identifies the higher-probability side, and compares its estimate with the uploaded moneyline's implied probability.
5. Review the matchup results and the underlying schedule, uploaded data, and leaderboards in the **Data** tab.

The displayed edge is the estimated probability minus the moneyline-implied probability, expressed in percentage points. It is a comparison, not a stake recommendation. The displayed data is a point-in-time snapshot and is not real-time.

## Requirements

- Network access for the app's schedule and statistics retrieval

## Important notes

- Schedule and statistics retrieval depends on the availability and structure of external pages; changes to those pages may interrupt parsing.
- Uploaded files, schedules, and calculated results are held in Streamlit session state; this project does not include persistent storage.
- Reloading sport data resets that sport's uploaded-file state, so upload the required files again after a reload.
- Moneyline-implied probabilities are derived directly from the uploaded odds; no odds-margin adjustment is applied in the frontend.
- Probabilities are estimates for informational and educational use only. They are not guaranteed to be accurate and are not financial advice. Please follow applicable laws and wager responsibly.
